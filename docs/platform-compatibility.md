# 平台兼容性测试

> 本文件是 [跨平台消息转发（`astrbot_plugin_msg_forward_cc`）](../README.md) 的平台兼容性测试记录，README 中只保留指向。

以下为 AstrBot 支持的全部平台之间**双向转发**测试记录。每个平台一张折叠表，表内为该平台作为**来源**转发至各**目标平台**的测试结果；**反向**（目标平台 → 该平台）结果见对应目标平台的表格。

> 本插件支持 AstrBot 官方全部平台适配器（aiocqhttp / qq_official / qq_official_webhook / telegram / wecom / wecom_ai_bot / lark / dingtalk / discord / slack / kook / vocechat / weixin_official_account / weixin_oc / satori / misskey / line / matrix / mattermost），最低 AstrBot 版本 **v4.0.0**。

> QQ官方机器人 同时覆盖 `qq_official` 与 `qq_official_webhook` 两个适配器。

测试内容分为 **文字 / 图片 / 语音 / 动图 / 视频 / 合并消息**（合并转发的聊天记录）**/ 文件** 七类，表内每列一类。点击平台名展开对应表格。

状态标记：✅ 通过　⚠️ 部分可用　❌ 失败　🚫 适配器不支持　⬜ 未测试

> 说明：测试需要两个会话均接入本插件并建立转发规则（如 `/mf bindraw qq 654321 tg 123456`）。同平台不同会话之间（如 QQ 群 A → QQ 群 B）同样需要测试。

已测试的 aiocqhttp 协议端：snowluma、LLOneBot、NapCat
